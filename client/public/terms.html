1. What the Service is

Pear-to-Pear is a free tool for transferring files directly between two people's browsers, with no account required. The Service consists of a web page and a signaling/relay server that helps two browsers connect and, when a direct connection isn't possible, streams encrypted data between them. See ARCHITECTURE.md for exactly how it works and PRIVACY.md for exactly what is and isn't seen or stored.

2. No accounts, no guaranteed identity

There is no sign-up and no identity verification. A "peer code" is a temporary, random session identifier. It does not verify who someone is. You are responsible for confirming you're bonding with the person you intend to, by sharing codes only through channels you trust and, for anything sensitive, verifying the six-digit security code described in SECURITY.md.
